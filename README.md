# Doets RAG Backend

RAG backend voor Doets Reizen kennisdatabank.

## Features
- Document upload (PDF, Word, TXT)
- Vector embeddings in Pinecone
- Smart retrieval bij AI vragen
- Admin panel

## Deployment
Deploy naar Vercel via GitHub.

Vereiste environment variables:
- PINECONE_API_KEY
- PINECONE_INDEX
